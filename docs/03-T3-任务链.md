## 2. 触发

```text
条件：无活跃任务链 && 冷却 = 0 && rng < p_task
命中：登记，本轮回复后生成
```

- 默认 `p_task = 0.25`、冷却 `3 游戏日`，面板可调；
- 冷却由插件按游戏日扣，完成/失败后启动；
- 同一时间只允许一条活跃任务链。

## 3. 种子（插件选，不靠 AI 发信号）

从以下来源按权重选一个，拼成“种子卡”：

- 当前地图区域（T4）；
- 势力冲突（T1 势力条目 + 世界状态）；
- 未触发的伏笔；
- 阶段事件（若启用阶段）。

种子卡只写：来源类型、地点、势力、伏笔名、一句钩子；**不给任务细节**。

## 4. 输入

- 种子卡；
- 本轮主 AI 正文（已发生事实，衔接用）；
- T1 目录中 `势力 / NPC / 物品资源 / 地理 / 规则禁忌` 条目（预算内）；
- 当前阶段、玩家状态、历史任务（防重复）；
- 当前地图（若有）。

## 5. 输出结构

```json
{
  "任务链": {
    "名称": "≤8字",
    "状态": "待激活",
    "任务时限": "N游戏日",
    "阶段归属": 1,
    "任务梗概": {
      "表面故事": "100-200字",
      "真实原委": "200-400字，含不干预会怎样",
      "关键NPC": [ { "名称": "", "表面立场": "", "真实立场": "", "核心动机": "" } ],
      "核心矛盾": "一句话两难"
    },
    "事件链": [
      { "序号": 1, "类型": "引子", "名称": "", "说明": "", "完成条件": "" }
    ],
    "结局": [
      { "类型": "表 | 真 | 失败", "触发条件": "", "即时后果": "", "后续影响": "" }
    ]
  }
}
```

约束：事件链 3–6 个，首个固定“引子”，至少 1 个“反转”；结局 ≥3，真结局必须有代价；编号由插件补。

## 6. 推进与维护（T2 v2.1）

- T2 每次生成返回 `任务链更新`：状态、当前节点、节点结果、结局、即时后果；
- 插件校验：节点序号必须存在于事件链；无链时输出“已完成”丢弃；完成必须带结局；
- 完成后：写 `task_history`、后续伏笔、启动冷却，链置空；
- 时限由插件按游戏日扣减，到期未完成判失败结局。

## 7. 展示

生成结果**不注入主 AI**，只把节点内容拼进 AI 回复的隐藏块（主 AI 读历史可见，玩家不可见）；面板另有完整查看。

## 8. 校验与降级

| 情况 | 处理 |
|---|---|
| 事件链不足 3 / 结局不足 3 | 重试一次，仍失败则丢弃本轮生成 |
| 节点序号越界 | 丢弃该更新，记日志 |
| 生成失败 | 保持无链，下轮重新掷骰 |
| 冷却被 AI 篡改 | 插件权威值覆盖 |

## 9. 验收

**离线**：结构校验、节点越界、冷却递减、完成写历史/伏笔断言。

**真机**：概率触发能复现（调试强制）；一轮内节点确实推进；完成后冷却生效、面板显示历史。
