# T5 · 命运事件 蓝图 v1.0（兼容 T2 v2.1）

- 状态：已定稿（2026-11-02）
- 上游：[00](00-执行逻辑与五任务基础说明-v0.1.md)、[01-T1](01-T1-世界模型.md)、[04-T4](04-T4-地图.md)
- 定位：把旧版“命运牌”改为**插件加权抽取事件**，事件库来自地图概率事件 + 伏笔 + 世界事件；默认不调 LLM。

## 1. 与旧版相比改了什么

| 旧版 | 新版 |
|---|---|
| 每 N 轮由 AI 出牌/静默 | 插件每轮掷骰，命中才抽 |
| 七张固定塔罗牌 | 事件库加权抽取，牌面只做包装（可选） |
| `fate_inject` 由 LLM 写 | 默认插件用“结果提示”拼注入，零调用 |
| 事件与地点无关 | 权重吃地图危险度与区域事件 |

## 2. 触发

```text
玩家点选行动、主 AI 生成前：
  if 冷却 = 0 && rng < p_fate:
      从事件库加权抽 1 条 → 拼 fate_inject → 随本轮注入
```

- 默认 `p_fate = 0.2`、冷却 2 轮，面板可调；
- 抽取是本地计算，无 LLM；若开启“演出扩写”，才多一次调用。

## 3. 事件库

```text
事件库 = 地图概率事件 + 未触发伏笔 + 世界事件（timeline_events）+ 阶段事件
每条 = { id, 名称, 类型, 权重, 触发条件, 结果提示, 来源 }
```

- 地图事件由 T4 产；
- 伏笔按剩余时间加权（越近越重）；
- 世界事件从 `timeline_events` 取，标“已触发”的不再抽。

## 4. 权重

```text
权重 = 基础权重 × 地点危险度系数 × 阶段系数 × 冷却/重复衰减
```

- 危险度：低 0.8 / 中 1.0 / 高 1.3；
- 阶段：越后期权重越向“危险/剧情”倾斜；
- 重复：最近 5 条抽过的事件权重 ×0.3。

## 5. 注入内容

```text
【命运事件】<事件名>
事件安排：<结果提示>
影响：<一句话后果>
```

- 注入位置：本轮 supplement 之前，短文本，预算 ≤ 300 字；
- 不写 NPC 台词、不替主 AI 决定玩家反应；
- 塔罗牌壳（牌名/正负性）作为可选展示，不影响抽取逻辑。

## 6. 校验与降级

| 情况 | 处理 |
|---|---|
| 事件库为空 | 跳过本轮，冷却不启动 |
| 抽中事件被标“已触发” | 剔除重抽，最多 3 次 |
| 注入超预算 | 截断“影响”句 |
| 开扩写但调用失败 | 回退默认拼接 |

## 7. 验收

**离线**：权重计算、重复衰减、冷却、抽取分布（固定种子）断言。

**真机**：命中后主 AI 正文出现对应事件；未命中不出现；冷却生效。

## 8. 里程碑

| M | 内容 | 退出 |
|---|---|---|
| M1 | 事件库拼装 | 夹具事件库完整 |
| M2 | 加权抽取 + 冷却 | 分布断言 |
| M3 | 注入拼装 | 预算断言 |
| M4 | 真机 | 命中/未命中断言 |
