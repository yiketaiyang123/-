# T4 · 地图 蓝图 v1.0（兼容 T2 v2.1）

- 状态：已定稿（2026-11-02）
- 上游：[00](00-执行逻辑与五任务基础说明-v0.1.md)、[01-T1](01-T1-世界模型.md)、[02-T2](02-T2-规则引擎.md)
- 定位：旧版地图方案的**兼容适配版**。保留区域/敌对/元素结构，新增“区域概率事件表”，供 T5 抽取；触发与维护改走 T2 v2.1。

## 1. 与旧版相比改了什么

| 旧版 | 新版 |
|---|---|
| 2A 发 `MAP_GEN` 才生成 | T2 返回场景类型变化 + 插件掷骰触发 |
| 地图只做区域结构 | 每区域新增概率事件表 |
| T2 生成前维护进度 | T2 回复后顺带返回 `地图更新` |
| `map_inject` 注入 | 删除，地图内容只进隐藏块 |

## 2. 触发

```text
T2 返回 场景.封闭 && 场景.是否变化 && (无地图 || 需要新地图) && rng < p_map
命中：本轮回复后生成
```

- 默认 `p_map = 0.5`，面板可调；
- 无地图时首次进入封闭场景必生成（不掷骰），之后换场景才掷。

## 3. 输入

- 场景描述（名称/概述/氛围/设施，来自 T2 的场景归类 + 正文）；
- T1 目录中 `地理 / 势力 / 事件 / 规则禁忌` 条目（预算内）；
- 当前阶段、玩家等级（敌对实力上限 = 当前等级段 + 2 段）；
- 本轮正文（衔接）；
- 旧地图（若存在，做增量或替换）。

约束：区域 3–15；隐藏区域 ≥1；连接目标必须存在；敌对 ≤4、BOSS ≤1；每区域概率事件 1–5 条；权重 1–100。

## 5. 推进与维护（T2 v2.1）

- T2 返回 `地图更新`：当前位置、已探索、区域状态；
- 插件校验：编号必须存在、已探索只增不减；
- 区域状态从“未探索→已探索→已清除”单向推进；
- 换图时旧图存档，不直接覆盖。

## 6. 展示

生成结果**不注入主 AI**，地图内容拼进 AI 回复的隐藏块；面板可看星图与区域详情。

## 7. 概率事件的用途

- 存进 `store.map`，T5 抽取时按“类型 × 权重 × 危险度 × 阶段”计算；
- 事件“结果提示”是给 T5 的素材，不是直接注入正文。

## 8. 校验与降级

| 情况 | 处理 |
|---|---|
| 区域数越界 / 连接悬空 | 重试一次，失败丢弃 |
| 敌对超上限 | 截断并记日志 |
| 概率事件权重非法 | 该条剔除 |
| 生成失败 | 保留旧图，下轮再掷 |

## 9. 验收

**离线**：结构校验、连接合法性、敌对上限、权重范围、概率事件表完整性。

**真机**：进入封闭场景触发一次；当前位置随剧情更新；已探索不回退；面板与隐藏块一致。
