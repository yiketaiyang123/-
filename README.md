# 命运编织者 · Ananke（重制版 v2）

SillyTavern 第三方扩展：在世界书基础上给主 AI 加一层"世界运行器"——

- 首次进入扫描角色卡世界书，分类成可用的世界资料；
- 按玩家背景生成 8 项属性（力量/敏捷/体质/感知/智力/意志/魅力/幸运）；
- 主 AI 每次回复后生成 **5 条行动选项**，点击后插件本地掷 1d100 检定，只把命中的成功/失败分支发给主 AI；
- 插件概率触发任务链、地图（含区域概率事件）与命运事件。

## 安装

1. 把本仓库放进 `SillyTavern/data/<用户名>/extensions/third-party/ananke`（或 `public/scripts/extensions/third-party/ananke`）。
2. 刷新酒馆页面。
3. 打开扩展菜单里的「命运编织者」，配置 API 或先开 Mock 调试。

## 依赖

- SillyTavern 1.13.x（在 1.13.4 上做过开发验证）。
- 不需要 Tavern Helper；只监听原生事件。
- 需要 OpenAI 兼容 API（经酒馆服务端代理调用）。

## 首次使用

1. 进入一个角色聊天；
2. 插件自动扫描世界书、生成属性（面板可看状态）；
3. 主 AI 回复后，消息底部出现 5 条行动选项；
4. 点击选项：插件掷 1d100，把行动 + 元叙事 + 命中分支填进输入框或直接发送；
5. 任务链 / 地图 / 命运事件按概率在后台生成。

## 面板

魔杖菜单「命运编织者」、悬浮球或 `/ananke` 打开，可配置：

- API 地址 / Key / 模型（或 Mock 调试）；
- 难度标签显示、点击模式（直接发送 / 只填输入框）；
- 任务链 / 地图 / 命运事件开关、概率、冷却；
- 重扫世界书、重生成属性、重置聊天数据、查看日志。

## 目录

```
manifest.json / index.js / v2.css
src/
  t1.js          世界书扫描、分类、属性生成
  t2.js          行动选项 + 任务链/地图维护
  t3.js / t4.js  任务链 / 地图生成
  t5.js          命运事件抽取
  scheduler.js   生成后调度
  attributes.js / checks.js  属性与 1d100 检定
  prompts.js     提示词
  ui/            面板与选项栏
docs/            设计文档（总说明 + T1–T5）
legacy/          旧版 v1 代码存档（不加载）
tools/           CDP 真机测试脚本
```
